# 📊 Chicago Public Data Analysis (2008–2012)

This project was completed as part of the IBM Data Science Professional Certificate on Coursera. Using real public datasets from the City of Chicago, I performed SQL-based analysis to uncover insights about crime rates, community hardship, and school performance across various community areas.

---

## 📚 Project Overview
This analysis focuses on:
- Crime data (2008–2012)
- Community census data (2008–2012)
- Chicago public school data (2008–2012)

## ⚙️ Tools & Technologies Used
- **Python** (Jupyter Notebook)
- **SQLite3** (`%sql` magic and `sqlite3` library)
- **SQL** (JOINs, subqueries, aggregate functions)
- **Pandas** for data handling

## 🔍 Project Tasks
- **Combined** Census data, Crime reports, and School performance data.
- **Calculated** metrics like Hardship Index by community.
- **Identified** high-crime neighborhoods and their attributes.
- **Compared** College enrollment rates with community factors.

## 🔍 Insights & Findings
Some key insights from the analysis include:

- 🔸 **Community Areas with Highest Crime Rates:**  
  Identified areas with the most reported crimes, revealing correlations with higher hardship index values.

- 🔸 **Relationship Between Community Hardship and School Enrollment:**  
  Communities with higher hardship scores tended to have lower college enrollment rates, indicating socioeconomic challenges impacting education.

- 🔸 **Top Crime Types by Community:**  
  Certain areas had higher occurrences of specific crime types (e.g., theft, assault), suggesting localized trends.

- 🔸 **Hardship Index Analysis:**  
  Calculated and compared hardship indices across communities to identify the most underserved areas.

- 🔸 **Crime Trends Over Time:**  
  Analyzed crime patterns between 2008 and 2012 to observe whether crime rates increased or decreased across specific neighborhoods.
